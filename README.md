# MediaPipe Pose Demostración

Este proyecto utiliza **MediaPipe** para realizar la detección y estimación de pose en tiempo real usando la cámara web. Está diseñado como parte de un modelo comparativo de diversos estimadores de pose para demostración.

## Requisitos
Para ejecutar este script, es recomendable usar un entorno virtual de Python para mantener las dependencias aisladas.

### Pasos para iniciar:
1. Instala las dependencias necesarias:
   ```bash
   pip install -r requirements.txt
   ```
2. Ejecuta el script:
   ```bash
   python mediapipe_pose.py
   ```
3. Para salir de la transmisión, presiona la tecla **`q`**.
