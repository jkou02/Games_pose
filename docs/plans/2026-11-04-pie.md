# Pie con punta y talón — Plan de Implementación

> **For agentic workers:** Implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Orientar el pie del avatar con el pitch y el yaw reales del sujeto y mantener la punta sobre el piso cuando se para en puntas.

**Architecture:** El backend agrega talón y punta al contrato. El frontend calcula la dirección del pie en el payload, aplica una rotación relativa sobre la pose de reposo del hueso del pie y compensa la altura del tobillo de apoyo con el pitch.

**Tech Stack:** Python 3.10 (`mediapipe`, `numpy`, `pytest`), Three.js 0.187 vendorizado, Flask.

**Spec:** `docs/specs/2026-11-04-pie-design.md`

## Global Constraints

- `landmarks` y `landmarks_2d` con 17 puntos.
- `confidence` se calcula sobre los 9 puntos del tren superior (no cambia).
- La orientación del pie es **relativa** a su pose de reposo; nunca se alinea el
  hueso contra `talón→punta`.
- Nunca modificar `position` de articulaciones por frame (`AGENTS.md` §7).
- Sin dependencias nuevas. Sin desplazamiento horizontal del avatar.

- [ ] **Step 2: Leer la dirección del pie del payload**

```js
/**
 * Dirección del pie en el payload: talón → punta.
 * Devuelve null si falta algún punto o si la distancia es implausible.
 */
function pieDelPayload(ladoPayload, landmarks) {
    const talon = landmarks?.[`${ladoPayload}_heel`];
    const punta = landmarks?.[`${ladoPayload}_foot_index`];
    if (!talon || !punta) return null;

    const v = new THREE.Vector3(punta[0] - talon[0], punta[1] - talon[1], punta[2] - talon[2]);
    const largo = v.length();
    if (largo < 0.05 || largo > 0.5) return null;
    v.normalize();

    const pitch = Math.asin(Math.max(-1, Math.min(1, -v.y)));
    return { forward: v, pitch: Math.max(-1.05, Math.min(1.05, pitch)) };
}

/** Frente del cuerpo en el espacio del modelo, a partir de `hips_side`. */
function frenteDelCuerpo(bones) {
    const side = bones?.hips_side;
    if (!side || side.every((v) => v === 0)) return null;
    const lateral = new THREE.Vector3(-side[0], 0, -side[2]);
    if (lateral.lengthSq() < 1e-6) return null;
    lateral.normalize();
    return new THREE.Vector3().crossVectors(lateral, MUNDO_ARRIBA).normalize();
}
```

```js
/** Orienta el pie con el pitch y el yaw del payload. */
function orientarPie(bone, punta, datos, restQuat, frente) {
    if (!bone || !restQuat) return;
    if (!datos) {
        // Respaldo: pie plano como antes del paso.
        const parentQ = new THREE.Quaternion();
        bone.parent.getWorldQuaternion(parentQ);
        bone.quaternion.slerp(parentQ.invert().multiply(restQuat), 0.3);
        estado.modelo3d.updateMatrixWorld(true);
        return;
    }

    const lateral = new THREE.Vector3().crossVectors(MUNDO_ARRIBA, datos.forward);
    const qPitch = lateral.lengthSq() > 1e-8
        ? new THREE.Quaternion().setFromAxisAngle(lateral.normalize(), datos.pitch)
        : new THREE.Quaternion();

    let qYaw = new THREE.Quaternion();
    if (frente) {
        const yawPie = Math.atan2(datos.forward.x, datos.forward.z);
        const yawCuerpo = Math.atan2(frente.x, frente.z);
        let delta = yawPie - yawCuerpo;
        delta = Math.atan2(Math.sin(delta), Math.cos(delta));
        qYaw = new THREE.Quaternion().setFromAxisAngle(MUNDO_ARRIBA, delta);
    }

    const mundo = qYaw.multiply(qPitch).multiply(restQuat);
    const parentQ = new THREE.Quaternion();
    bone.parent.getWorldQuaternion(parentQ);
    bone.quaternion.slerp(parentQ.invert().multiply(mundo), 0.5);
    estado.modelo3d.updateMatrixWorld(true);
}
```

### Defectos encontrados midiendo

1. **La compensación solo se aplicaba al pie de apoyo.** Con los dos pies en
   puntas, el libre hundía la punta 3,9 unidades. Ahora se aplica a ambos.
2. **La altura del tobillo se calculaba con el pitch del payload**, sin sumar la
   inclinación de reposo del hueso (39°): sobrecompensaba y dejaba la punta 2,3
   unidades flotando. La fórmula correcta es
   `largoPie · (sin(θreposo + pitch) − sin(θreposo))`.
