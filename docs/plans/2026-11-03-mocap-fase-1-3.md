# MoCap Avatar 3D — Plan de Implementación Fases 1-3

> **For agentic workers:** Implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir el pipeline completo de captura de pose con MediaPipe, difusión por WebSocket y escena Three.js con avatar, cumpliendo el contrato de datos del proyecto.

**Architecture:** Arquitectura productor-consumidor desacoplada. Un backend Python captura frames, extrae `pose_world_landmarks`, los transforma al espacio Three.js y difunde JSON por WebSocket local. Un frontend Vite + Three.js consume el JSON, y en esta etapa sólo muestra escena, avatar y estado de conexión. El mapeo cinemático a huesos queda explícitamente fuera de alcance (Fase 4).

**Tech Stack:** Python 3.10 (`mediapipe`, `opencv-contrib-python`, `websockets`, `numpy`, `pytest`), Node 24 (`vite`, `three`).

**Spec:** `AGENTS.md` (secciones 2, 3, 4, 5, 7). Este plan implementa **sólo** Fases 1, 2 y 3.

## Global Constraints

- Python 3.10+.
- WebSocket local en `ws://127.0.0.1:8765` por defecto.
- Payload JSON exactamente con las claves: `timestamp`, `detected`, `confidence`, `landmarks`, `bones`.
- Transformación obligatoria: `x_3d = -x_mp`, `y_3d = -y_mp`, `z_3d = -z_mp`.
- Landmarks en metros, **relativos al centro de cadera**.
- `bones` son vectores **unitarios** normalizados.
- Origen del backend en `127.0.0.1` por defecto (no exponer a la red sin decisión explícita).
- Prohibido modificar `position` de huesos hijos en el frontend (aplica desde Fase 4, se respeta el diseño).
- Latencia objetivo del pipeline < 100 ms por frame.
- No implementar: filtros de suavizado, Foot IK, arte final, manos/rostro (sección 6 del spec).

## Decisiones ya acordadas con el usuario

| Tema | Decisión |
|---|---|
| Fuente de video | CLI `--source`, acepta índice (`0`) o URL RTSP. Default `0`. |
| Frontend | Vite + `three`, build estático servible sin internet. |
| Avatar | Placeholder geométrico incluido en el repo; loader `.glb` listo para reemplazo. |
| `mediapipe` | Se mantiene `0.10.9` (sin `jax`), con `numpy` 1.x. |

## Hallazgos previos que este plan corrige

1. `requirements.txt` es insatisfacible: `opencv-contrib-python==4.13.0.92` exige `numpy>=2` mientras `mediapipe` requiere `numpy<2`. Se fija `opencv-contrib-python==4.10.0.84` + `numpy==1.26.4` (compatible con `mediapipe==0.10.9`).
2. `ReconstruccionPose.py:30` contiene credenciales RTSP en texto plano. Se parametriza por variable de entorno.
3. El ejemplo del contrato en `AGENTS.md` §3 muestra `nose: [0.0, 1.65, 0.1]`, que corresponde a altura absoluta y contradice el texto "relativas a la cadera". Este plan implementa **relativo a cadera** (el texto normativo).
4. El contrato no define hueso `head`, pero la Fase 4 lo requiere. **Se decide al cerrar la Fase 3**; este plan no lo agrega.
5. No existe `.gitignore`; `AGENTS.md` está sin trackear.

```python
# backend/kinematics.py
"""Transformación de landmarks de MediaPipe a espacio Three.js y vectores óseos.

Módulo puro: no importa mediapipe. La entrada son secuencias de 33 puntos o
landmarks con atributos .x/.y/.z.
"""

from __future__ import annotations

from typing import Sequence

import numpy as np

NOSE = 0
LEFT_SHOULDER = 11
RIGHT_SHOULDER = 12
LEFT_ELBOW = 13
RIGHT_ELBOW = 14
LEFT_WRIST = 15
RIGHT_WRIST = 16
LEFT_HIP = 23
RIGHT_HIP = 24

#: Subconjunto del contrato: índice MediaPipe -> clave del payload.
LANDMARK_KEYS: dict[int, str] = {
    NOSE: "nose",
    LEFT_SHOULDER: "left_shoulder",
    RIGHT_SHOULDER: "right_shoulder",
    LEFT_ELBOW: "left_elbow",
    RIGHT_ELBOW: "right_elbow",
    LEFT_WRIST: "left_wrist",
    RIGHT_WRIST: "right_wrist",
    LEFT_HIP: "left_hip",
    RIGHT_HIP: "right_hip",
}

#: Segmentos del contrato: nombre -> (índice origen, índice destino).
BONE_DEFINITIONS: dict[str, tuple[int, int]] = {
    "right_upper_arm": (RIGHT_SHOULDER, RIGHT_ELBOW),
    "right_lower_arm": (RIGHT_ELBOW, RIGHT_WRIST),
    "left_upper_arm": (LEFT_SHOULDER, LEFT_ELBOW),
    "left_lower_arm": (LEFT_ELBOW, LEFT_WRIST),
}

_EPS = 1e-8


def _xyz(landmark) -> tuple[float, float, float]:
    if hasattr(landmark, "x"):
        return float(landmark.x), float(landmark.y), float(landmark.z)
    return float(landmark[0]), float(landmark[1]), float(landmark[2])


def to_three_space(point: Sequence[float]) -> np.ndarray:
    """Aplica x_3d = -x, y_3d = -y, z_3d = -z (AGENTS.md §4)."""
    x, y, z = float(point[0]), float(point[1]), float(point[2])
    return np.array([-x, -y, -z], dtype=np.float64)


def normalize_landmarks(raw) -> dict[str, np.ndarray]:
    """Convierte landmarks crudos a metros, centrados en la cadera, en espacio Three.js."""
    points = {
        name: to_three_space(_xyz(raw[idx])) for idx, name in LANDMARK_KEYS.items()
    }
    hip_mid = (points["left_hip"] + points["right_hip"]) / 2.0
    return {name: point - hip_mid for name, point in points.items()}


def unit(vec: Sequence[float]) -> np.ndarray:
    """Normaliza; devuelve vector nulo si la norma es despreciable."""
    arr = np.asarray(vec, dtype=np.float64)
    norm = float(np.linalg.norm(arr))
    if norm < _EPS:
        return np.zeros(3, dtype=np.float64)
    return arr / norm


def compute_bones(points: dict[str, np.ndarray]) -> dict[str, np.ndarray]:
    """Vectores unitarios de cada segmento del contrato."""
    bones = {
        name: unit(points[LANDMARK_KEYS[end]] - points[LANDMARK_KEYS[start]])
        for name, (start, end) in BONE_DEFINITIONS.items()
    }
    hip_mid = (points["left_hip"] + points["right_hip"]) / 2.0
    shoulder_mid = (points["left_shoulder"] + points["right_shoulder"]) / 2.0
    bones["torso_up"] = unit(shoulder_mid - hip_mid)
    return bones


def to_list(vec: Sequence[float], decimals: int = 4) -> list[float]:
    """Redondea para reducir ancho de banda del payload."""
    return [round(float(component), decimals) for component in vec]
```

```python
# backend/schema.py
"""Construcción y serialización del payload JSON (AGENTS.md §3)."""

from __future__ import annotations

import json
import time
from typing import Mapping, Sequence

from backend.kinematics import to_list


def build_payload(
    landmarks: Mapping[str, Sequence[float]],
    bones: Mapping[str, Sequence[float]],
    confidence: float,
    detected: bool = True,
    timestamp: float | None = None,
) -> dict:
    """Arma el paquete estándar de un frame detectado."""
    return {
        "timestamp": round(float(time.time() if timestamp is None else timestamp), 3),
        "detected": bool(detected),
        "confidence": round(float(confidence), 3),
        "landmarks": {name: to_list(vec) for name, vec in landmarks.items()},
        "bones": {name: to_list(vec) for name, vec in bones.items()},
    }


def empty_payload(timestamp: float | None = None) -> dict:
    """Paquete de frame sin detección: el avatar debe volver a pose neutra."""
    return {
        "timestamp": round(float(time.time() if timestamp is None else timestamp), 3),
        "detected": False,
        "confidence": 0.0,
        "landmarks": {},
        "bones": {},
    }


def serialize(payload: Mapping) -> str:
    """JSON compacto para minimizar ancho de banda."""
    return json.dumps(payload, separators=(",", ":"))
```

```python
# backend/capture.py
"""Fuente de video configurable: webcam local, archivo o RTSP."""

from __future__ import annotations

import cv2
import numpy as np


def parse_source(raw: str) -> int | str:
    """Convierte '0' en índice de cámara; deja URLs y rutas como texto."""
    value = raw.strip()
    if value.isdigit():
        return int(value)
    return value


class CameraSource:
    """Envoltura mínima de cv2.VideoCapture con configuración opcional."""

    def __init__(
        self,
        source: int | str,
        width: int = 1280,
        height: int = 720,
        fps: int = 30,
    ) -> None:
        self.source = source
        self.width = width
        self.height = height
        self.fps = fps
        self._cap: cv2.VideoCapture | None = None

    def open(self) -> bool:
        self._cap = cv2.VideoCapture(self.source)
        if not self._cap.isOpened():
            return False
        self._cap.set(cv2.CAP_PROP_FRAME_WIDTH, self.width)
        self._cap.set(cv2.CAP_PROP_FRAME_HEIGHT, self.height)
        self._cap.set(cv2.CAP_PROP_FPS, self.fps)
        return True

    def read(self) -> np.ndarray | None:
        if self._cap is None:
            return None
        ok, frame = self._cap.read()
        if not ok:
            return None
        return frame

    def release(self) -> None:
        if self._cap is not None:
            self._cap.release()
            self._cap = None
```

```python
# backend/pose_engine.py
"""Extracción de pose con MediaPipe y armado del payload."""

from __future__ import annotations

import cv2
import mediapipe as mp
import numpy as np

from backend.kinematics import LANDMARK_KEYS, compute_bones, normalize_landmarks
from backend.schema import build_payload, empty_payload


class PoseEngine:
    """Procesa frames BGR y devuelve payloads listos para difundir."""

    def __init__(self, min_confidence: float = 0.5, model_complexity: int = 1) -> None:
        self.min_confidence = min_confidence
        self._pose = mp.solutions.pose.Pose(
            static_image_mode=False,
            model_complexity=model_complexity,
            min_detection_confidence=0.5,
            min_tracking_confidence=0.5,
        )

    def process(self, frame_bgr: np.ndarray) -> dict:
        rgb = cv2.cvtColor(frame_bgr, cv2.COLOR_BGR2RGB)
        results = self._pose.process(rgb)

        if not results.pose_world_landmarks:
            return empty_payload()

        raw = results.pose_world_landmarks.landmark
        visibility = [float(raw[index].visibility) for index in LANDMARK_KEYS]
        confidence = float(np.mean(visibility)) if visibility else 0.0

        if confidence < self.min_confidence:
            return empty_payload()

        points = normalize_landmarks(raw)
        bones = compute_bones(points)
        return build_payload(points, bones, confidence)

    def close(self) -> None:
        self._pose.close()
```

```python
# backend/server.py
"""Difusión broadcast de payloads a clientes WebSocket."""

from __future__ import annotations

import asyncio
import logging

logger = logging.getLogger(__name__)

SEND_TIMEOUT = 0.1


class Broadcaster:
    """Registro de clientes y envío tolerante a fallos."""

    def __init__(self) -> None:
        self._clients: set = set()

    @property
    def client_count(self) -> int:
        return len(self._clients)

    async def register(self, websocket) -> None:
        self._clients.add(websocket)
        logger.info("Cliente conectado (%d activos)", self.client_count)

    async def unregister(self, websocket) -> None:
        self._clients.discard(websocket)
        logger.info("Cliente desconectado (%d activos)", self.client_count)

    async def broadcast(self, message: str) -> None:
        """Envía a todos; descarta clientes que fallen o excedan el timeout."""
        if not self._clients:
            return
        await asyncio.gather(
            *(self._send(websocket, message) for websocket in list(self._clients)),
            return_exceptions=True,
        )

    async def _send(self, websocket, message: str) -> None:
        try:
            await asyncio.wait_for(websocket.send(message), timeout=SEND_TIMEOUT)
        except Exception:
            self._clients.discard(websocket)
```

```python
# backend/main.py
"""Punto de entrada: captura -> MediaPipe -> WebSocket."""

from __future__ import annotations

import argparse
import asyncio
import logging
import time

from websockets.asyncio.server import serve

from backend.capture import CameraSource, parse_source
from backend.pose_engine import PoseEngine
from backend.schema import serialize
from backend.server import Broadcaster

logger = logging.getLogger("mocap")


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(description="Servidor MoCap MediaPipe -> WebSocket")
    parser.add_argument("--source", default="0", help="Índice de cámara (0) o URL RTSP")
    parser.add_argument("--host", default="127.0.0.1", help="Interfaz de escucha")
    parser.add_argument("--port", type=int, default=8765, help="Puerto WebSocket")
    parser.add_argument("--width", type=int, default=1280)
    parser.add_argument("--height", type=int, default=720)
    parser.add_argument("--fps", type=int, default=30, help="FPS solicitado a la cámara")
    parser.add_argument("--max-fps", type=float, default=60.0, help="Tope de difusión")
    parser.add_argument("--model-complexity", type=int, choices=(0, 1, 2), default=1)
    parser.add_argument("--min-confidence", type=float, default=0.5)
    parser.add_argument("--log-level", default="INFO")
    return parser


async def run(args: argparse.Namespace) -> int:
    camera = CameraSource(
        parse_source(args.source),
        width=args.width,
        height=args.height,
        fps=args.fps,
    )
    if not await asyncio.to_thread(camera.open):
        logger.error("No se pudo abrir la fuente de video: %s", args.source)
        return 1

    engine = await asyncio.to_thread(PoseEngine, args.min_confidence, args.model_complexity)
    broadcaster = Broadcaster()
    min_interval = 1.0 / args.max_fps if args.max_fps > 0 else 0.0

    async def handler(websocket) -> None:
        await broadcaster.register(websocket)
        try:
            await websocket.wait_closed()
        finally:
            await broadcaster.unregister(websocket)

    logger.info("Escuchando en ws://%s:%d", args.host, args.port)
    frames = 0
    processed = 0
    window_start = time.perf_counter()
    last_sent = 0.0

    try:
        async with serve(handler, args.host, args.port) as _server:
            while True:
                frame = await asyncio.to_thread(camera.read)
                if frame is None:
                    await asyncio.sleep(0.01)
                    continue

                payload = await asyncio.to_thread(engine.process, frame)
                frames += 1
                if payload["detected"]:
                    processed += 1

                now = time.perf_counter()
                if min_interval == 0.0 or (now - last_sent) >= min_interval:
                    last_sent = now
                    await broadcaster.broadcast(serialize(payload))

                if frames % 100 == 0:
                    elapsed = now - window_start
                    logger.info(
                        "%.1f FPS | detectado %d/%d | clientes %d | conf %.2f",
                        frames / elapsed if elapsed > 0 else 0.0,
                        processed,
                        frames,
                        broadcaster.client_count,
                        payload["confidence"],
                    )
                    frames = 0
                    processed = 0
                    window_start = now
    except (KeyboardInterrupt, asyncio.CancelledError):
        logger.info("Cerrando servidor")
        return 0
    finally:
        await asyncio.to_thread(camera.release)
        await asyncio.to_thread(engine.close)


def main() -> int:
    args = build_parser().parse_args()
    logging.basicConfig(
        level=getattr(logging, args.log_level.upper(), logging.INFO),
        format="%(asctime)s %(levelname)s %(name)s: %(message)s",
    )
    try:
        return asyncio.run(run(args))
    except KeyboardInterrupt:
        return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```javascript
const DEFAULT_URL = 'ws://127.0.0.1:8765'

export function createPoseSocket({
  url = DEFAULT_URL,
  onPose,
  onStatus,
  reconnectDelay = 1000,
} = {}) {
  let socket = null
  let closedByUser = false
  let attempt = 0

  const setStatus = (state, detail = '') => onStatus?.({ state, detail, url })

  function connect() {
    setStatus('connecting')
    socket = new WebSocket(url)

    socket.onopen = () => {
      attempt = 0
      setStatus('connected')
    }

    socket.onmessage = (event) => {
      try {
        onPose?.(JSON.parse(event.data))
      } catch (error) {
        console.warn('Payload inválido del backend', error)
      }
    }

    socket.onerror = () => setStatus('error')
    socket.onclose = () => {
      if (closedByUser) return
      setStatus('disconnected')
      attempt = Math.min(attempt + 1, 10)
      setTimeout(connect, reconnectDelay * attempt)
    }
  }

  connect()

  return {
    close() {
      closedByUser = true
      socket?.close()
    },
  }
}
```
